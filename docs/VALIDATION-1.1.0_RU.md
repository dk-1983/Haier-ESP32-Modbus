# Приёмочные проверки v1.1.0

Дата: 2026-09-22. Плата ESP32-S3-WROOM-1 N16R8 подключена к работающему кондиционеру Haier.

- Чистая CI-сборка из `dc116e95495efe7cf3f51ecd1423d5d11973282a`: прошли тесты MQTT/Modbus/паролей/сравнения версий, 50 000 некорректных Modbus PDU, Discovery, 2000 проверок hOn/CRC, компиляция и упаковка бинарников.
- Веб-пароль изменён, старый отклоняется. Независимый OTA-пароль изменён и проверен реальной ArduinoOTA-загрузкой. Пароли и запрет обновлений сохранились после перезапусков и прошивки. Исходный веб-доступ восстановлен.
- Некорректный CSRF-токен, недопустимые пароли и значения политики отклоняются.
- Манифест GitHub с неправильной подписью получен по проверенному HTTPS (HTTP 200) и отклонён без смены прошивки. При выключенной политике установка возвращает HTTP 409.
- Подписанный публичный бинарник v1.1.0 скачан из GitHub Releases, проверен, записан в неактивный раздел и запущен. Раздел сменился с `app1` на `app0`, подтверждение загрузки через 45 секунд прошло. MD5 работающего приложения: `7a5f89f5bfc5a46a7161e83c678b25c8`; SHA-256 релиза: `fd8c58f50ce3ce56cff01b8c6de235e2cb5f37d1c29d87e6643fa8dcc16e812b`.
- Охлаждение сохранилось: ON, COOL 22 °C, вентилятор AUTO, качание OFF, preset NONE, quiet OFF, дисплей ON, оба направления CENTER. Свежие ответы hOn доступны.
- Проверены соответствие factory/OTA и все SHA-256 пакета. В публичном образе нет значений личных паролей миграционной сборки.

Ограничения: первичная настройка на физически стёртой плате и принудительный откат не испытывались на работающем контроллере. Нативные тесты проверки паролей не заменяют аппаратный тест первого запуска. Ограничение отката при раннем сбое приложения сохраняется; см. [управление](MANAGEMENT_RU.md). Проверки не означают отсутствие всех возможных ошибок.
