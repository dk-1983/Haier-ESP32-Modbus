# Установка прошивки пошагово

**В релизе v1.0.0 опубликованы только исходники. Готового `.bin` в Assets нет.** «Source code (zip)» — архив для распаковки и сборки, его нельзя записывать в ESP. Пароли настройки и web/OTA в этой версии задаются при сборке, поэтому нужно указать собственные. Ниже — весь путь от скачивания релиза до запуска контроллера.

## 1. Скачайте релиз и подготовьте Windows

Нужны **ESP32-S3-WROOM-1 N16R8** (16 МБ Flash, 8 МБ octal PSRAM) и USB-UART с **логическими уровнями 3,3 В**. Эта прошивка не предназначена для ESP8266 или оригинального Wi-Fi-модуля Haier.

1. Установите **Python 3.11** с Python Launcher и **Git**, затем заново откройте PowerShell.
2. Откройте [релиз v1.0.0](https://github.com/dk-1983/Haier-ESP32-Modbus/releases/tag/v1.0.0), раскройте **Assets**, скачайте **Source code (zip)** и распакуйте.
3. Откройте PowerShell в распакованной папке с `haier-s3.yaml` и `Build.ps1`. Проверьте команды `py -3.11 --version` и `git --version`.

## 2. Задайте свои пароли

```powershell
Copy-Item secrets.example.yaml secrets.yaml
notepad secrets.yaml
```

Замените оба примера, сохранив кавычки YAML:

- `setup_password` — пароль точки доступа контроллера; используйте 8–63 символа ASCII.
- `ota_password` — пароль пользователя `admin` в веб-интерфейсе и ArduinoOTA; задайте надёжный личный пароль.

Сохраните файл. Домашняя сеть Wi-Fi настраивается после прошивки через веб-страницу. Не публикуйте `secrets.yaml` и собранные с вашими паролями образы.

## 3. Соберите прошивку

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Скрипт создаст окружение Python и скачает закреплённые зависимости компилятора. Для первой сборки нужен Интернет; она может занять время. Дождитесь успешного завершения. При ошибке сначала исправьте её. Сама сборка ничего не записывает в плату.

При текущей конфигурации файлы появляются в `.esphome/work/build/.pioenvs/haier-s3/`:

| Файл | Назначение |
|---|---|
| `firmware.factory.bin` | Первая запись через USB-UART: объединённый образ загрузчика, таблицы разделов и программы; адрес **0x0** |
| `firmware.bin` | Образ программы для **ArduinoOTA** на уже прошитом контроллере |

Не записывайте `firmware.bin` по адресу 0x0. Если изменён путь сборки, используйте пути из её вывода.

## 4. Подключите программатор

Первую запись выполняйте на столе, отключив контроллер от кондиционера. Соединяйте провода при снятом питании; обеспечьте подходящий источник питания платы. Голому модулю нужны стабилизированные 3,3 В, не 5 В; слабого выхода 3,3 В программатора может не хватить.

| USB-UART | ESP32-S3 |
|---|---|
| TX с логикой 3,3 В | GPIO44 / RXD0 |
| RX | GPIO43 / TXD0 |
| GND | GND |

GPIO17/18 — UART кондиционера, **не порт программирования**. Питание и BOOT подключите по [схеме](SCHEMATIC_RU.md). Номер COM найдите в **Диспетчере устройств → Порты (COM и LPT)**; при необходимости установите драйвер изготовителя адаптера. Закройте мониторы порта, которые могут занимать его.

## 5. Включите режим загрузки

Для нашего макета с ручным управлением: снимите питание → удерживайте **PGM/BOOT** (GPIO0 на GND) → подайте питание → отпустите PGM. На отладочной плате обычно можно удерживать BOOT и нажать/отпустить RESET. GPIO0 должен быть низким в момент сброса, EN после сброса — высоким.

## 6. Запишите полный образ

Установите esptool в окружение сборки. В следующей команде замените **COM6** на свой порт:

```powershell
.\work\tools\Scripts\python.exe -m pip install "esptool>=5,<6"
.\work\tools\Scripts\python.exe -m esptool --chip esp32s3 --port COM6 --baud 460800 --before no-reset --after no-reset write-flash 0x0 .esphome/work/build/.pioenvs/haier-s3/firmware.factory.bin
```

Дождитесь успешной записи и проверки хеша. Если соединения нет, проверьте COM, перекрёстное подключение TX/RX, GND и режим загрузки. Если запись обрывается на высокой скорости, повторите с `--baud 115200`. Полное стирание памяти для этой инструкции не требуется: оно удаляет сохранённые настройки.

Команда специально оставляет модуль в режиме загрузки: **перезапустите питание без нажатия PGM/BOOT**, чтобы запустить программу.

## 7. Настройте Wi-Fi и откройте управление

1. Подключитесь к **`haier-s3-<suffix>-setup`** с вашим `setup_password`.
2. Откройте **http://192.168.4.1**, выберите свою сеть **2,4 ГГц** и сохраните её реквизиты.
3. Верните компьютер/телефон в обычную сеть. Найдите выданный контроллеру IP в списке DHCP-клиентов роутера.
4. Откройте `http://DEVICE_IP/control`; логин **admin**, пароль — ваш `ota_password`.
5. Снимите питание перед подключением UART Haier по [схеме](SCHEMATIC_RU.md), включая согласование уровня RX. После запуска проверьте получение свежего состояния кондиционера.
6. Настройте [MQTT / Home Assistant](MQTT_RU.md) или [Modbus](SYSTEM_RU.md). Изначально MQTT и транспорты Modbus выключены.

## 8. Последующие обновления по Wi-Fi

Здесь используется **ArduinoOTA, порт 8266**, а не собственный OTA-протокол ESPHome. Соберите новую версию с выбранными паролями и используйте `espota.py` из Arduino framework, скачанного `Build.ps1`:

```powershell
.\work\tools\Scripts\python.exe work/platformio/packages/framework-arduinoespressif32/tools/espota.py -i DEVICE_IP -p 8266 -a "CURRENT_OTA_PASSWORD" -f .esphome/work/build/.pioenvs/haier-s3/firmware.bin
```

Замените IP и пароль. Для авторизации нужен пароль **текущей установленной** прошивки; после обновления действует пароль, заданный в новой сборке. Компьютер должен быть в той же локальной сети; разрешите загрузчику соединения через брандмауэр. Дождитесь завершения и перезапуска, затем проверьте `/control`. Не публикуйте пароль в снимках экрана и истории команд. **Не отправляйте `firmware.factory.bin` через OTA.**

Источники: [Espressif esptool](https://docs.espressif.com/projects/esptool/en/latest/esp32s3/esptool/) и [командная строка ESPHome](https://esphome.io/guides/cli/). Пины, пути и порт OTA выше сверены с конфигурацией нашего проекта.
