# Безопасность

Проект предназначен для доверенной локальной сети. Modbus TCP не использует авторизацию или TLS; не открывайте порт502 в Интернет. Реквизиты setup и пароль OTA/web должны находиться только в неотслеживаемом secrets.yaml. Web Basic передаётся по обычному HTTP; при необходимости используйте изоляцию сети. RTU/TCP изначально выключены и включаются независимо. Заводские ключи и прошивки не распространяются.

В сообщениях об ошибках приводите минимальный пример без паролей, MAC-адресов и личных сетевых данных. Перед публичным раскрытием эксплуатируемой уязвимости свяжитесь с сопровождающим репозитория по указанному им каналу связи.

В публичном v1.1.0 нет общего пароля администратора/OTA. На новой плате подключитесь к точке настройки с `Haier-Setup` и сразу задайте личные пароли web, OTA и AP перед настройкой Wi-Fi. Доступ к начальной AP позволяет выполнить первое назначение паролей. Сохранённые реквизиты имеют приоритет над встроенными и переживают OTA. Смена требует авторизации (либо доступа с начальной AP до настройки) и CSRF-токена текущего запуска. Образы GitHub проверяются по HTTPS, подписи ECDSA ключом проекта, SHA-256 и профилю платы. См. [управление](docs/MANAGEMENT_RU.md).
